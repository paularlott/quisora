Signing keys

They sign every token this server issues, in every organization. Applications pick up new keys by themselves, and tokens already issued keep working. If a key may have been exposed, rotate now, then remove the old key: the tokens it signed stop working at once, and applications get new ones through their refresh tokens.

Emergency sign-out

Ends every session in every organization at once, on every node: browser sessions, and the refresh tokens of every application, so their access tokens stop working through this server too. Optionally personal API tokens as well. Your own session stays. Everyone can sign in again at once. To sign out one organization, use its page.

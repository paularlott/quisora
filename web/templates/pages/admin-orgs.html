Passwords and lockout

API tokens for applications

Personal API tokens that the organization's own applications check through Quisora; an application also has to accept them in its own settings. Tokens for SCIM and the administration API follow people's roles, whatever is chosen here. Tokens already made are kept: turning this off stops them working, and turning it on again brings them back.

Tokens may last forever.

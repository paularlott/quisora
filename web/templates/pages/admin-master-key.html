How a rotation goes

  1. Make a new key with quisora genkey.
  2. On every node: the old key stays server.master_key, the new one goes in server.previous_master_keys; reload (SIGHUP) or restart.
  3. On every node: the new key becomes server.master_key, the old one moves to server.previous_master_keys; reload or restart. The re-seal starts once every node seals with the new key.
  4. When this page says so, remove server.previous_master_keys on every node; reload or restart.

A single node skips step 2. The same status is GET /api/master-key.
